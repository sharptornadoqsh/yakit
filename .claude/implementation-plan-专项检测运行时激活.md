# 专项检测运行时激活实施计划

生成时间：2026-07-29 10:27:54 +08:00

**目标：** 专项检测首次下载插件后，通过引擎自身数据库初始化逻辑生成内置关键词分组，使当前
引擎连接和当前页面立即显示插件，不重启桌面程序、窗口或当前引擎。

**方案：** 下载流结束后，Electron 主进程以相同主目录和数据库环境运行一个有界的一次性引擎
帮助命令。该命令执行引擎既有数据库后置初始化并退出；主进程随后使用原通信客户端验证专项分组，
页面再执行一次现有分组查询并更新状态。

## 任务一：建立主进程失败测试

**文件：**

- 新增：`app/main/__test__/specialDetectionActivation.test.js`

**验收：**

- 一次性进程退出码为零后返回运行结果。
- 非零退出、启动错误和超时分别返回可识别错误。
- 超时会终止一次性进程，输出收集存在上限。
- 生产模块建立前，测试因模块缺失而失败。

## 任务二：建立页面与下载协议失败测试

**文件：**

- 修改：`app/renderer/src/main/src/pages/securityTool/yakPoC/__test__/YakPoCPluginPresentation.test.tsx`
- 修改：`app/renderer/src/main/src/pages/mitm/MITMServerHijacking/__test__/YakitGetOnlinePlugin.test.tsx`

**验收：**

- 下载结束后先调用专项运行时激活，再查询分组。

- 下载提示可以显示索引刷新和查询验证阶段。
- 激活或查询异常与下载流异常保持区分。

## 任务三：实现有界运行时激活单元

**文件：**

- 新增：`app/main/specialDetectionActivation.js`

**验收：**

- 使用固定引擎路径和固定帮助命令，不经过命令外壳。
- 继承当前引擎主目录及数据库环境。
- 设置超时、输出上限、退出码和启动错误处理。
- 不触发桌面程序或当前引擎生命周期操作。

协议、不删除用户分组，不产生需要回退的数据格式。
