## 技术方案

`tombstones` 是允许未定义的响应字段。读取三个数组字段前将缺失值规范化为空对象，随后保留原有数组检查：

```typescript
const tombstones: ApiEntity = nextSync.tombstones ?? {}
```

该方案不修改服务类型、同步响应、状态更新、合并算法或构建配置。
