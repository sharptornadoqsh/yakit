# 专项检测首次下载自动刷新实施计划

生成时间：2026-07-28

**目标：** 专项检测首次下载插件资源成功后，在当前页面自动显示关键词分类与插件列表，无需重启应用。

**方案：** 以下载流结束事件为唯一成功边界，通过下载组件已有的异步完成回调重新查询专项插件分类。
下载组件等待刷新成功后关闭，专项页面用最新响应替换分类状态，并忽略过期或卸载后的异步结果。

**技术栈：** React、TypeScript、Electron 进程间通信、Vitest、Testing Library。

## 全局约束

- 不使用应用重启、`location.reload`、渲染器重载、菜单跳转、固定延时或无限轮询。
- 不修改远程过程调用、协议、数据库、插件分组底层能力与其他漏洞检测页面。
- 保持关键词模式、纯名称展示、插件选择与执行逻辑，以及此前全部睿眼界面策略。
- 不新增第三方依赖，不进行无关重构或格式整理。
